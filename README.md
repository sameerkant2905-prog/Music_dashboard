# 🎵 Music Player Dashboard

A modern and responsive Music Player Dashboard built using HTML, CSS, and JavaScript.

## ✨ Features

- 🎧 Play / Pause functionality
- ⏮️ Previous & ⏭️ Next controls
- 📂 Multiple song playlist
- ⏱️ Progress bar with live timing
- 🔊 Volume control
- 💿 Rotating album cover
- 🌈 RGB glow animations
- ❤️ Favorite, 🔀 Shuffle, 🔁 Repeat icons
- 📱 Responsive design
- ⚡ Smooth UI animations

## 🛠️ Technologies Used

- HTML
- CSS
- JavaScript
- Font Awesome
- AOS Animation Library

## 📸 Preview

Interactive music player with playlist support and a modern UI experience.

## 🚀 How to Run

1. Download the project
2. Open `index.html`
3. Enjoy the music player 🎶
